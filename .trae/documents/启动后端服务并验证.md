## 前置检查
- 确认 Node.js 已安装（建议 18+）：`node -v`
- 依赖安装：在 `c:\Users\lgfx6\Desktop\Web\SinoGearQuote\SinoGearQuote\backend` 执行 `npm install`
- 端口与跨域：当前后端端口为 `5006`（见 `backend/.env`），CORS 允许 `http://localhost:3000`（见 `backend/server.js`）
- 数据库模式：目前 `server.js` 中 `useMockData=true`，后端会使用模拟数据启动；如需真实数据库，请先完成 MongoDB 安装并将其改为 `false`

## 启动后端
- 开发模式（自动重载）：在 `backend` 目录执行 `npm run dev`
- 或生产模式：在 `backend` 目录执行 `npm start`
- 成功日志：应看到 `服务器运行在 http://localhost:5006`

## 运行验证
- 健康检查：打开 `http://localhost:5006/health`，期望返回 `{ status: "ok", message: "服务器运行正常" }`
- API 验证：
  - 车型：`GET http://localhost:5006/api/models`
  - 颜色：`GET http://localhost:5006/api/colors`
  - 内饰：`GET http://localhost:5006/api/interiors`
- 静态资源：上传目录通过 `http://localhost:5006/uploads/...` 可访问

## （可选）切换到真实数据库
